6 条核心流程走查 点击卡片内链接逐页走查

流程 1 · 首学漏斗

发现了 → 记住了 → 留下来

落地页 → 词书详情（SEO） → 游客试学 5 词 → 注册（合并进度） → 首次设置 → 今日首页

PRD 4.1 · 首学漏斗 ≥60% 关键：注册门槛在第一次正反馈之后。

流程 2 · 每日学习

先复习 → 再新词 → 打卡

今日首页 → 复习（四选一） → 新词学习 → 当日完成 / 打卡

PRD 4.2 · FR-03/08 · 一次点击进入有效任务；退出实时续接。

流程 3 · 新词自评循环

不认识的词本轮必重现

三态自评决策 → 认识 L2 (3) · 模糊 L1 (1) ＋ 本轮重现 · 不认识 轮末重现至记成

PRD 4.3 · FR-04 · 保证每次学习都发生记忆。

流程 4 · 复习与间隔决策

客观四选一 · 答错回队尾

四选一作答 → 正确 等级 +1 按间隔表排下次 → 错误 等级清零 · 回今日队尾 · 明日优先

PRD 4.4 · FR-05/06 · 防偷看（绝不显示释义）。

流程 5 · 缺席回归容错

积压分批 · 无惩罚

今日首页（积压态） → 分批容错面板 → 先复习第一批 / 先学新词均可

PRD 4.5 · FR-07 · 回归首日任务量 ≤ 上限；禁止「放弃」式文案。

流程 6 · 词书切换

多词书并行 · 进度独立

词书列表 → 新书从第 1 词开始 → 统计页合并展示 · 设置页管理

PRD 4.6 · FR-11 · 切回旧书进度分毫不丢。
