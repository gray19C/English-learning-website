## 三、标注条格式规范（每页顶部必含）

```html
<div class="prd-ref">
  对应 PRD：§4.2 · FR-03 / FR-08 · 用户故事 6.2 / 6.3 · 里程碑 M2 / M3 · 流程：每日学习
</div>
```

字段取值以本表第一节行为准：
- `§4.x`：对应核心流程（无则 `—`）
- `FR-xx`：对应功能需求（冒号分隔）
- `用户故事`：对应 §6 小节
- `里程碑`：M1–M4
- 页面用途一句话与前后页走查链接，保留在页面内的 `note` 注释块中
